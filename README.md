# 📚 读书笔记 PWA

> 🌐 **在线使用**：<https://pancong0711.github.io/reading-notes-pwa/>
> （手机/平板浏览器打开 → 菜单「添加到主屏幕」→ 像 App 一样使用）

一个**纯本地**的读书笔记应用：没有服务器、没有云端、没有账号。你的笔记只存在两处——
你自己的设备（浏览器本地存储）和你自己的电脑（CLI 管理的 JSON sidecar / 源文档，可选）。笔记中的图片、音频、视频和文档附件也保存在本机。
「添加到主屏幕」后离线可用。

---

## 一、三步上手

1. **打开网页**：手机浏览器访问上面的网址 → 首次访问后即离线可用（建议「添加到主屏幕」）。
2. **导入你的笔记包**（可选）：页面「⚙️ 数据」→「📥 导入文件」→ 选择一个笔记包 JSON（格式见下文 §三；没有数据也可以直接开始写新笔记）。
3. **开始使用**：导航 →「📒 笔记」写新笔记；「阅读足迹」看热力图；「知识图谱」看概念关联。

---

## 二、数据在哪里？（隐私模型）

| 位置 | 内容 |
|------|------|
| 浏览器本地（IndexedDB） | 你导入/撰写的全部笔记、图片/音频/视频/文档附件、概念标签 |
| 你的电脑（可选） | JSON sidecar 为编辑真源；md/html/txt/docx 等源文档只读保留 |
| 服务器 | **无**。本站是纯静态页面，任何数据都不上传 |

- 换手机/换浏览器 = 新的空库，用「⬇ 备份 / 迁移包」导出 JSON 带走（可勾选含媒体附件）。
- 电脑端 CLI 可导入 md/html/txt/docx，并为每篇文档生成 `源文件名.note.json` 管理记录。
- 清除浏览器数据会清空本地库——**定期导出备份**。
- 多终端之间**不自动同步**：靠「导出 → 传输（微信/网盘/AirDrop）→ 导入」显式搬运，这是刻意的 local-first 设计。

## 三、笔记包 JSON 格式（对接/手写必读）

一个笔记包就是一个 JSON 文件。两种合法形态：

**形态 A（推荐，完整包）**：

```json
{
  "schemaVersion": 3,
  "exportedAt": "2026-09-17T12:00:00.000Z",
  "notes": [ "…记录数组…" ],
  "books": [],
  "conceptCatalog": { "domains": [], "concepts": [] },
  "imageFiles": { "assets/xx.jpg": "data:image/jpeg;base64,…", "assets/rec.webm": "data:audio/webm;base64,…" }
}
```

（`books` / `conceptCatalog` / `imageFiles` 均可省略；`imageFiles` 虽沿用旧字段名，但可携带图片/音频/视频/文档等任意媒体附件；最简形态是直接一个记录数组 `[ { … }, { … } ]`。）

### 单条记录的字段

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `id` | 建议 | 字符串 | 稳定唯一标识。**多端合并的匹配依据**——要让"在旧笔记基础上更新"生效，同一条笔记在各端必须同 id。不填则每次导入视为新笔记 |
| `type` | 否 | 字符串 | `general`（一般笔记，新记录默认）/ `note`（阅读笔记）/ `diary` / `log` / `memo` / 自定义类型 key |
| `title` | 建议 | 字符串 | 标题（缺省显示「未命名笔记」） |
| `date` | 建议 | `YYYY-MM-DD` | 笔记日期，列表按此排序 |
| `book` | 否 | 字符串 | 书名（阅读笔记用） |
| `content` | 否 | 字符串 | 正文，Markdown 子集（粗体/斜体/标题/列表/代码块/表格/`$公式$`/`==高亮==`/`~~删除线~~`/受控逐字格式/媒体块） |
| `tags` | 否 | 字符串数组 | 自由标签，如 `["物理", "热力学"]` |
| `concepts` | 否 | 数组 | 知识图谱概念标注（id 数组或对象数组） |
| `project` | 否 | 字符串 | **文件夹路径**，`/` 分层级，如 `"读书/物理"`；缺省自动归入 `other` |
| `updatedAt` | 建议 | 毫秒时间戳 | **合并的版本依据**：导入时包内较新者覆盖内容。不填则用包的 `exportedAt` 兜底 |
| `readerNote` / `aiNote` / `quotes` / `characters` / `extension` | 否 | 可选 | 读者注 / AI 注 / 金句 / 人物 / 延伸阅读 |
| `images` | 否 | 字符串数组 | 旧兼容图片相对路径；新记录优先使用 `media` |
| `contentFormat` | 否 | 字符串 | `markdown`（默认）/ `html` / `text`；决定正文渲染器 |
| `source` | 否 | 对象 | 来源元数据：`kind/path/originalName/sha256/importedAt/importedFrom` 等 |
| `media` | 否 | 数组 | 四类媒体附件：`{kind:"image|audio|video|file",src,name,mime,size,caption,widthPercent,rotate,align,alt}`；正文用 `![](src){kind=...}` 引用 |
| `style` | 否 | 对象 | 文档级字体/对齐/行距/首行缩进白名单 |
| `typeData` / `extensions` | 否 | 对象 | 类型字段快照与扩展字段；切换类型不丢旧 key |
| `pinned` | 否 | 布尔 | 本端置顶偏好 |

### 最小可导入示例（复制即可用）

```json
{
  "schemaVersion": 3,
  "exportedAt": "2026-09-17T12:00:00.000Z",
  "notes": [
    {
      "id": "my-note-001",
      "type": "note",
      "title": "熵",
      "book": "万物简史",
      "date": "2026-09-17",
      "content": "熵是无序度的度量。$S = k \\ln W$",
      "tags": ["物理", "热力学"],
      "project": "读书/物理",
      "updatedAt": 1758108000000
    },
    {
      "id": "my-diary-001",
      "type": "diary",
      "title": "9月17日",
      "date": "2026-09-17",
      "content": "今天整理了 4 篇笔记。",
      "tags": ["生活"],
      "updatedAt": 1758108000000
    }
  ],
  "books": []
}
```

### 缺省与合并行为（重要）

- **无 `project`** → 自动归入 `other` 文件夹（不留空）。
- **无 `id`** → 按 `type+book+title+date` 回退匹配；建议始终带稳定 `id`。
- **导入策略**（导入对话框三选一）：
  - **智能合并**：包内较新的记录**更新本端内容**；但 `project`/`tags`/`concepts` **归属以本端为准**（本端有归属就保留，本端为空才从包补齐）——更新笔记不会冲掉你在这台设备上的文件夹/标签管理；本端较新的记录原样保留。
  - **仅新增**：只导入本端没有的记录，不覆盖任何现有内容。
  - **完整替换**：清空本端，以包为准重建（危险操作，会先自动备份）。
- **删除不跨端同步**：在一端删除的笔记，另一端合并时**不会被删除**（无墓碑机制，刻意简化）。
- 导入前会**自动下载一份备份** JSON。

## 四、数据进出三通道

1. **PWA ↔ PWA**（手机↔平板/换机）：A 设备「⚙️ 数据 → ⬇ 备份 / 迁移包」（默认含媒体附件）→ 传输文件 → B 设备「📥 导入文件」→ 智能合并。
2. **电脑 CLI（进阶）**：电脑端有完整命令行应用（Markdown 真相源 + PDF 导出 + 索引）：
   - 电脑 → 手机：`reading-notes sync` 生成 `export.json` → 传手机 → 导入
   - 手机 → 电脑：「⬇ 备份 / 迁移包」导出 → `reading-notes import-json 笔记包.json --strategy merge`
3. **手写/第三方生成**：按 §三 的字段写 JSON，直接导入。

## 五、功能一览

- 📒 **笔记模块**：阅读笔记/日记/日志/备忘统一管理，**文件夹**（可多层路径 `父/子`）组织；空文件夹也可直接新建；卡片「⋯」操作（编辑 / 移动 / 删除 / 置顶）；多选批量移动/删除
- 📊 阅读热力图（年 / 近6月 / 近3年三尺度，拖拽缩放）
- 🕸️ 知识图谱（概念 → 笔记可视化，本机可重算）＋ 🧭 概念管理（增删改、未编目概念一键收集）
- 🏷️ 自由标签整理（重命名/删除/合并）
- 📷 **完整多媒体入口**：单击拍照、长按录像；相册/本机文件均可多选；麦克风直接录音；图片、音频、视频、PDF/Office/压缩包等附件统一管理
- 🖼️ **HEIC/HEIF 兼容**：鸿蒙/手机 HEIC 自动在本机转 JPEG，离线组件不上传服务器；图片压缩到长边 ≤1600px
- 📝 **独立编辑页**：标题/正文优先，附加字段折叠；固定保存栏、防连点、未保存确认与自动草稿；新建后回到原文件夹并高亮
- 🎛️ 媒体非破坏式版式：图片旋转/宽度/对齐/图注，音视频/文档保留受控播放器或下载链接，原文件不改
- ✏️ 富文本编辑 + 公式（MathJax 离线渲染）、`==高亮==`/`~~删除线~~`/表格
- 📄 多格式笔记：导入/编辑 md/html/txt；HTML 使用 sandbox 安全预览；DOCX/DOC 由电脑 CLI 转换
- 🅰️ 文档级字体/对齐/行距白名单，PWA 与 PDF 同口径
- 🔠 阅读字号四档（存本机）＋ 📖 书页模式（双页翻页）
- 🗂️ 类型注册表 JSON 导入/导出，可与电脑 CLI 双向同步
- 🖨 导出/生成：打印草稿（另存 PDF）/ 下载书稿 markdown
- 📴 离线可用（Service Worker 缓存；页脚显示缓存版本号）

## 六、多格式与类型同步（可选进阶）

### 多格式笔记

- 数据中枢「📥 导入文件」支持 JSON 笔记包与 `.md/.html/.txt`；
- 导入后统一存为 JSON 记录，原文件不被 App 回写；
- HTML 正文在 sandbox iframe 中阅读/预览，打印时使用白名单清洗；
- DOCX/DOC 不内置 Office 转换器：电脑端运行
  `reading-notes note import-file 文件.docx --project 资料` 转换后，再把 JSON 同步到 PWA。

### 类型 JSON 双向同步

- PWA：「⚙️ 数据 → 管理类型」→「⬇ 导出类型 JSON」/「📥 导入类型 JSON」；
- CLI：

```bash
reading-notes type export -o note-types.json
reading-notes type import note-types.json
```

契约：

```json
{ "schemaVersion": 1, "types": [
  { "key": "idea", "label": "灵感", "icon": "💡", "fields": ["book"] }
] }
```

## 六、自部署（GitHub Pages）

想自己部署一份（完全不经过作者的 Pages）：

1. GitHub 新建**空仓库**（公开/私有均可）
2. 把本仓库内容全部推上去：
   ```bash
   git init && git add . && git commit -m "init" && git push
   ```
3. 仓库 → Settings → Pages → Source: `Deploy from a branch` → `main` / 根目录 → Save
4. 等 1-2 分钟访问 `https://<你的用户名>.github.io/<仓库名>/`

> 更新版本：替换文件后记得把 `sw.js` 里 `CACHE_NAME` 版本号 +1，否则老用户拿不到新缓存。

## 七、FAQ

- **数据会传到服务器吗？** 不会。页面是纯静态文件，数据只在你设备的浏览器里。
- **清除浏览器数据会怎样？** 本地库清空。请先「⬇ 备份 / 迁移包」导出。
- **两台设备怎么保持一致？** 定期互导；智能合并会按 `updatedAt` 取新内容，并保留各端自己的文件夹/标签管理。
- **支持其他语言？** 界面为中文；笔记内容任意语言均可。
- **我的 Markdown 原文件会被修改吗？** 不会。App 编辑写 JSON，原 md/html/txt 源文件只读；手工修改源文件后需显式重新导入。
- **图片旋转会改原图吗？** 不会。只保存显示属性；PDF 导出时使用临时旋转图。
- **HEIC 图片能用吗？** 可以。PWA 会在本机把 HEIC/HEIF 转为 JPEG；若浏览器/设备不支持，会明确提示转换失败。
- **音视频和文档附件会上传吗？** 不会。全部存本机 IndexedDB，随迁移包导出时才会进入你选择传输的 JSON 文件。
- **图标**：「添加到主屏幕」暂用默认图标。
